# RHAP — Rural Hockey Access Program

A responsive informational website based on the supplied RHAP PowerPoint presentation.

## Preview
Open `index.html` in a browser. No build tools required.

## Deploy with GitHub Pages
Create a GitHub repository, upload the contents of this folder to the repository root, then visit Settings → Pages → Deploy from branch → main / root.

## Important
RHAP is a proposed program. The registration costs, participation figures, and impact percentages are targets, not current results. No registration, donation, or contact forms are active. Replace placeholder contact information and verify all details before launching publicly.

Images and branding are extracted from the user-supplied PowerPoint; review licensing and permissions before public distribution. Some presentation photos are illustrative or generated.
